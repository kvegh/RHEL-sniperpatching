# OLD track

This directory is self-contained for its seven demo playbooks. Select its full
`playbooks/old/<stage>.yml` path in AAP, with this track's protected environment
inputs, inventory and execution environment. Generic survey definitions remain
at the repository's `surveys/` directory.

See the [project guide](../../README.md) and [operations](../../docs/operations.md).

The OLD tree preserves the previously tested runtime behavior. Existing AAP
template names and protected inputs are preserved; their CaC paths now point
to this directory. Historical exact-revision test results remain historical.
